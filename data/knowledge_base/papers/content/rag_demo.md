# 论文知识库问答系统说明

本知识库用于演示 Langchain-Chatchat 的本地 RAG 问答能力。

RAG 是 Retrieval-Augmented Generation 的缩写，意思是检索增强生成。系统会先从本地文档知识库中检索与问题相关的文本片段，再把这些片段作为上下文交给大语言模型生成回答。

一个适合论文和专业文档问答的 RAG 系统通常包含五个核心步骤：文档解析、文本切分、向量化、相似度检索、基于上下文生成答案。

向量数据库选型时应重点考虑：是否支持本地部署，是否支持中文和长文本检索，索引构建速度，查询延迟，数据规模，持久化能力，备份迁移难度，以及与应用框架的集成成本。

在论文问答场景中，推荐回答时保留来源片段或文件名，避免模型脱离文档内容自由发挥。对于扫描版 PDF，还需要 OCR；对于表格、公式和图片较多的论文，需要额外处理版面和结构化信息。
